Semester 1–2

Python adalah bahasa pertama yang benar-benar membuat saya jatuh cinta dengan pemrograman. Semester pertama, saya ingat betul senang ketika berhasil membuat program sederhana yang menampilkan nama saya di layar. Rasanya seperti menemukan bahasa baru yang memungkinkan saya berbicara dengan komputer. Saya mulai dari hal-hal paling dasar—memahami bagaimana menyimpan data, menghitung, dan membuat keputusan. Setiap baris kode yang berjalan memberikan kepuasan tersendiri.

  • Variabel & Tipe Data
  • Input & Output
  • Operator Aritmatika
  • Percabangan (if-else)
  • Perulangan (for/while)
  • Fungsi Dasar

Semester 2–3

Membangun Struktur: Dunia yang Lebih Kompleks

Setelah dasar terkuasai, saya mulai menantang diri dengan hal yang lebih kompleks. Saya ingat ketika pertama kali membuat program yang bisa membaca dan menulis data ke file—rasanya seperti memiliki superpower! Saya belajar mengelola data dengan list dan dictionary, menangani error agar program tidak mudah crash, dan membuat kode yang lebih modular dengan fungsi. Setiap tantangan yang berhasil saya selesaikan membuat pemahaman saya tentang Python semakin dalam.

  • Manipulasi String & List
  • Nested Loops
  • Error Handling (Try-Except)
  • File Handling
  • Modular Programming
# Membaca Data dari File
try:
    with open("data.txt", "r") as file:
        isi = file.read()
        print("Isi file:", isi)
except FileNotFoundError:
    print("File tidak ditemukan!")
Semester 3–4

Menuju Aplikasi Nyata: Kekuatan Objek

Di titik ini, saya tidak lagi puas hanya membuat skrip kecil. OOP mengubah cara pandang saya sepenuhnya—seolah-olah saya belajar merancang dunia digital sendiri dengan Class dan Object. Saya bahkan mencoba membuat aplikasi GUI sederhana, dan rasanya luar biasa bisa membuat program yang berinteraksi dengan pengguna melalui antarmuka visual. Saya juga mendalami struktur data seperti stack dan queue, yang membuat program saya lebih efisien dan cepat.

  • OOP (Class & Object)
  • Inheritance
  • GUI (Tkinter)
  • Searching & Sorting
  • Stack & Queue
class Mahasiswa:
    def __init__(self, nama, nim):
        self.nama = nama
        self.nim = nim

    def tampilkan_info(self):
        print(f"Mahasiswa: {self.nama} ({self.nim})")

mhs = Mahasiswa("Bagus", "24050974004")
mhs.tampilkan_info()
