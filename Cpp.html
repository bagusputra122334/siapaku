Jejak Langkah Pemrograman C++

Semester 1–2

Gerbang Logika: Fondasi & Sintaks Dasar

Ketika pertama kali belajar C++, rasanya seperti memasuki dunia baru yang penuh ketelitian. Berbeda dengan Python yang fleksibel, C++ memaksa saya untuk benar-benar memahami apa yang terjadi di balik layar. Saya ingat betul kesalahan pertama saya—lupa menutup kurung atau salah menuliskan sintaks yang membuat program error berulang kali. Tapi setiap kesalahan itu justru mengajarkan saya tentang pentingnya ketelitian dan pemahaman fundamental.

  • Struktur Dasar (#include)
  • Input/Output (cin/cout)
  • Variabel & Tipe Data
  • Operator Logika
  • Percabangan (if/switch)
  • Perulangan (for/while)
#include <iostream>
using namespace std;

int main() {
    string nama;
    cout << "Masukkan nama: ";
    cin >> nama;
    cout << "Halo " << nama;
    return 0;
}
Semester 2–3

Modularitas: Mengorganisir Kode dengan Fungsi

Di semester ini, saya belajar bagaimana memecah program besar menjadi bagian-bagian kecil yang lebih mudah dikelola dengan fungsi. Saya ingat ketika pertama kali membuat program yang menggunakan array dan fungsi secara bersama-sama—rasanya seperti menyusun puzzle yang akhirnya berjalan dengan sempurna. Meskipun konsep pointer terasa membingungkan pada awalnya, tapi ketika saya mulai memahaminya, saya menyadari betapa powerful-nya kontrol yang diberikan oleh C++ terhadap memori.

  • Array 1D & 2D
  • String (C-Style)
  • Function & Parameter
  • Pointer Dasar
  • Rekursi
  • Modular Programming
int tambah(int a, int b) {
    return a + b;
}

// Penggunaan fungsi dalam program
int hasil = tambah(10, 5);
Semester 3–4

Dunia Tingkat Lanjut: Pointer, OOP, & Struktur Data

Fase ini benar-benar menguji kemampuan saya. Pointer, konsep yang ditakuti banyak orang, justru menjadi titik balik saya dalam memahami cara kerja komputer secara mendalam. Saya menghabiskan banyak jam untuk memahami Linked List, Stack, dan Queue—struktur data yang mengubah cara saya mengorganisir informasi. Dengan OOP di C++, saya bisa merancang sistem yang kompleks dengan cara yang terstruktur dan mudah dikembangkan. Meskipun sulit, kepuasan ketika program berjalan sempurna tidak tergantikan!

  • Pointer Lanjutan (*p, &x)
  • Struct & Class
  • Encapsulation & Inheritance
  • Linked List, Stack, Queue
  • File Handling (fstream)
  • Sorting & Searching
// Contoh Pointer & Class
class Mahasiswa {
public:
    string nama;
    void tampil() {
        cout << "Nama: " << nama;
    }
};

int x = 10;
int *p = &x; // p menyimpan alamat x
Analisis & Perbandingan

C++ vs Python: Dua Sisi Mata Uang

Menguasai kedua bahasa ini memberikan saya keajaiban tersendiri. Python menjadi pilihan utama ketika saya ingin mengimplementasikan ide dengan cepat dan fleksibel. Sedangkan C++ adalah senjata andalan ketika saya butuh performa tinggi dan kontrol penuh terhadap sistem. Kombinasi keduanya membuat saya menjadi pengembang yang lebih adaptif dan siap menghadapi berbagai tantangan.
