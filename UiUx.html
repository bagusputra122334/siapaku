Semester 1–2

Mata Kreatif: Dasar Desain & Visual

Dunia desain menjadi pelarian kreatif saya di tengah kesibukan pemrograman. Di semester awal, saya belajar tentang hal-hal dasar yang ternyata sangat penting—teori warna, tipografi, dan prinsip desain seperti kontras, repetisi, dan keselarasan. Saya ingat betul ketika pertama kali memahami bahwa warna tidak hanya indah, tapi juga bisa mempengaruhi emosi dan perilaku pengguna!

  • Contrast & Alignment

Semester 2–3

Arsitektur Digital: Masuk ke Dunia UI/UX

Ketika memasuki UI/UX, saya menyadari bahwa desain bukan hanya tentang keindahan— tapi tentang bagaimana pengguna berinteraksi dengan produk. Saya belajar membuat wireframe dan user flow, yang mengajarkan saya untuk berpikir dari sudut pandang pengguna. Pertama kali menggunakan Figma, rasanya seperti memiliki kanvas digital yang memungkinkan saya mewujudkan ide dengan cepat dan fleksibel!

  • Konsep UI (User Interface)
  • Layout Web & Mobile
  • Wireframe (Sketsa)
  • User Flow (Alur)
  • Usability Dasar
Figma
Semester 3–4

Pengalaman Manusia: UX + Prototyping

Di tahap ini, pemahaman saya tentang desain menjadi semakin dalam—desain bukan hanya tentang tampilan, tapi tentang pengalaman manusia. Saya belajar membuat user persona, memetakan user journey, dan membangun design system untuk konsistensi. Yang paling seru adalah ketika membuat prototype interaktif di Figma—rasanya seperti melihat ide kita menjadi nyata dan bisa diuji oleh pengguna!

  • User Persona & Journey
  • UX Research & Testing
  • Prototyping Interaktif
  • Design System
  • Evaluasi UX
